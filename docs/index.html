Portfolio Optimization Lab

投資組合優化實驗室

An open-source Python toolkit for mean-variance and risk-parity portfolio optimization built on CVXPY — plus a fixed-iteration ADMM reference kernel for research into hardware acceleration (FPGA / ASIC) of convex optimization for low-latency rebalancing.

以 CVXPY 實現均值-方差及風險平價投資組合優化的開源 Python 工具庫，並附固定迭代次數的 ADMM 參考核心，用於研究以硬件加速（FPGA / ASIC）凸優化、實現低延遲再平衡。

02 · Risk parity

Equalising risk, sweep by sweep 逐步平衡風險貢獻

Starting from equal weights, coordinate descent adjusts one asset at a time until every asset contributes the same share of total risk. Each update is a closed-form root — only multiply-adds and one square root.
由等權重出發，坐標下降法逐一調整資產，直至每項資產對總風險的貢獻相同。每步更新都有解析解，只需乘加運算及一次開方。

03 · Research direction

Toward hardware-accelerated rebalancing 硬件加速再平衡（研究方向）

Low-latency rebalancing needs a solver with predictable run time. An ADMM iteration with a pre-factorised KKT matrix uses only matrix-vector products, additions and clamps for a fixed number of iterations — a structure that maps naturally onto pipelined FPGA / ASIC logic. This repository contains the software reference model only; no hardware has been built.
低延遲再平衡需要運行時間可預測的求解器。預先分解 KKT 矩陣後，每次 ADMM 迭代只涉及矩陣向量乘法、加法及截斷，迭代次數固定，適合映射到流水線式 FPGA / ASIC 電路。本代碼庫只包含軟件參考模型，尚未製作任何硬件。

Concept diagram of the solver data path · 求解器數據通路概念圖（研究方向，非已實現硬件）

Does reduced precision still converge? 降低精度仍能收斂嗎？

The same 200-iteration ADMM run in float64, float32 and emulated 12-bit fixed-point. Lower precision converges at first, then stalls at a noise floor — the kind of trade-off (word length vs. accuracy vs. chip area) the hardware research studies.
同一個 200 次迭代的 ADMM 分別以 float64、float32 及模擬 12 位定點數運行。低精度起初同樣收斂，之後停在噪聲底線——這正是硬件研究要權衡的問題（字長、精度與晶片面積）。

04 · Use it

Five lines to a portfolio 快速上手

# pip install -e .   (from the cloned repository)
import portfolio_lab as pl

market = pl.synthetic_market(n_assets=8, seed=0)        # synthetic data only
mu     = pl.mean_returns(market.returns)
cov, _ = pl.ledoit_wolf_covariance(market.returns)

pl.max_sharpe(mu, cov).weights                 # mean-variance (CVXPY)
pl.risk_parity(cov)                            # equal risk contributions
pl.rebalance(current, mu, cov, gamma=3, cost=0.002)  # with transaction costs
pl.mean_variance_admm(mu, cov, gamma=3, precision="float32")  # hardware reference kernel
